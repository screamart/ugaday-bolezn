# План: Угадай болезнь

Бриф: `.claude/features/guess-the-disease.md` (пока лежит в `/home/user/.claude/features/`, на шаге 1 переносим в репозиторий).
Прототип: https://claude.ai/artifact/G22EfQ7YWQxbRHz1pkYQTX. Исходник: `/tmp/claude-0/-home-user/8f7751ac-4008-5e36-8913-ef162649a663/scratchpad/proto-guess-the-disease.html`, 1469 строк.

## Контекст

Делаем веб-игру «Угадай болезнь» для iPhone. Её открывают по ссылке в Safari, ничего не устанавливая. Механику и вид мы утвердили в прототипе: объяснялка на 1–4 команды. Для одной команды — игра на рекорд с переворотом карточки, пока карточка открыта, таймер стоит. Таймер-градусник, последнее слово, итоги хода с правкой, финал «Выписка». Персонажи — SVG, рисуются кодом.

Нужно перенести прототип в настоящий проект: колода из 60 карточек, адаптивная вёрстка под реальные iPhone, офлайн-режим, публикация на GitHub Pages.

## Что нашёл

- Репозиторий `screamart/ugaday-bolezn` пустой: ни одного коммита, ветка `main`. Он склонирован в `/home/user/ugaday-bolezn` и подключён к сессии с правом push.
- Образцов и конвенций в проекте нет. Образец — сам прототип, весь код берём оттуда:
  - **данные:** `SYS`, `CARDS`, `PDEF`;
  - **арт:** `BODY`, `eye`, `mouth`, `face`, `limbs`, `props`, `decor`, `artSVG`;
  - **экраны:** `scrHome` … `scrFinal`, `cardHTML`, `soloCardHTML`, `renderScreen`;
  - **логика:** `startGame`, `startTurn`, `beginTurn`, `answer`, `flip`, `isHeld`, `goLast`, `endTurn`, `toggleRes`, `nextTurn`, `toFinal`, `pause`, `resume`, `buildDeck`, `drawCard`, `reshuffle`, `restoreGame`;
  - **ввод:** свайп, клавиатура, `visibilitychange`;
  - **окружение:** звук `tone`/`sound`, Wake Lock, `confetti`, CSS «игрового мира».
- Окружение:
  - **GitHub CLI** в сессии не авторизован, поэтому включить GitHub Pages через API я не смогу — это один клик у вас.
  - **Workflow-файлы** (`.github/workflows`) могут не пройти push из-за прав токена, поэтому без GitHub Actions: Pages раздаёт файлы прямо из `main`.
  - **Инструменты:** Node 22 и Playwright с Chromium есть, Google Fonts отвечает (200).

## Архитектурное решение

**Чистые HTML + CSS + JS-модули без сборки и без зависимостей.** Что лежит в репозитории, то и раздаёт GitHub Pages: никакой сборки, которая может сломаться. Игра — один экран, фреймворк не нужен. Safari давно поддерживает ES-модули.

- **Логика отдельно от DOM.** `js/game.js` — чистое состояние и переходы: без `document` и `window`, а время приходит параметром `tick(dt)`. Побочные эффекты (звук, тост, «+1», Wake Lock) модуль отдаёт через колбэк `emit(event)`. Поэтому все правила брифа можно проверить автотестами в Node (`node --test`).
- **Вёрстка.** Экраны и стили переносим из прототипа почти как есть. Меняется одно: вместо фиксированного кадра 402×874 — реальный экран:
  - высота `100dvh`, отступы через `env(safe-area-inset-*)`;
  - картинка карточки сжимается на маленьких экранах, а шрифты брифа (название ≥32, жалобы ≥18) не уменьшаются;
  - на компьютере игра идёт по центру колонкой до 480 px на фоне кафеля.
- **Офлайн и «На экран Домой».** `manifest.webmanifest` плюс `sw.js` (stale-while-revalidate, кэш с номером версии). Шрифты лежат в репозитории как woff2 (лицензия OFL), а не берутся с Google: так работает офлайн и не зависит от чужого сервера. Все пути относительные (`./`), потому что игра живёт по адресу `screamart.github.io/ugaday-bolezn/`.
- **Отладочная галерея.** `deck.html` — отдельная страница со всеми 60 персонажами, чтобы вы проверили арт. В игре на неё ссылок нет.
- **Отклонено.** Vite + TypeScript: нужен шаг сборки и деплой через Actions, а для одного экрана это лишняя сложность и лишний риск.

## Тесты и проверка

**Автотесты** (`npm test`, то есть `node --test tests/`), в `game.test.js`:
- угадали +1, пропуск −1 и 0 без штрафа;
- последнее слово: «Не угадали» = 0, ход заканчивается;
- время не может кончиться, пока идёт смена карточки;
- игра на рекорд:
  - до переворота ответить нельзя;
  - пока карточка открыта, таймер стоит, после ответа идёт;
  - время кончается только при закрытой карточке;
- колода: нет повторов, сыгранные запоминаются между партиями, перемешивание без карточек текущего хода;
- круги и переход хода, финал, ничья, рекорд;
- правка в итогах пересчитывает счёт;
- пауза останавливает время;
- восстановление: ход превращается в паузу, отсчёт — в передачу хода;
- спам: во время блокировки второй ответ не засчитывается;
- счёт может уйти в минус.

**E2E** (`npm run e2e`): три размера iPhone и компьютер, обе версии игры, нет ошибок, нет горизонтальной прокрутки, кнопки целиком на экране, скриншоты.

**Вручную на вашем iPhone** — чек-лист из граничных случаев брифа:
- свернуть Safari посреди хода;
- закрыть вкладку и открыть снова;
- беззвучный режим;
- повернуть телефон;
- «На экран Домой» и запуск без интернета;
- экран не гаснет во время хода.

## Риски

- **Высота экрана в Safari меняется вместе с панелями, а iPhone SE маленький.** Используем `100dvh`, картинка карточки сжимается. E2E проверяет 375×667.
- **Новые карточки окажутся хуже прототипных.** Галерея `deck.html` и ваше «да» до push на этапе 2.
- **Service worker отдаёт старую версию.** Stale-while-revalidate: обновление приходит при следующем запуске. Номер версии кэша поднимаем при каждом релизе, это правило записано в `CLAUDE.md`.
- **Звук на iPhone молчит в беззвучном режиме.** Так устроен Safari, бриф это допускает: таймер всё равно пульсирует.
- **Wake Lock не поддерживается в старых iOS.** Если отказ — игра просто идёт дальше без него.
- **Репозиторий публичный.** Код, журнал и тексты видны всем. Секретов в проекте нет.
