## Бриф: Угадай болезнь (утверждён 2026-10-20)
**Суть**: веб-игра для компании на одном iPhone: объясняющий видит карточку с шуточным персонажем-болячкой и описывает симптомы, не называя болезнь; его команда угадывает на время.
**Зачем**: быстрое весёлое развлечение для вечеринки/пары 30+ без установки — открыл ссылку в Safari и играешь; смешно за счёт неловких тем и мультяшного арта.
**Как работает**:
1. Настройка: 1–4 команды (имена по умолчанию шуточные: «Терапевты», «Хирурги», «Лоры», «Санитары», можно переименовать), длительность хода, число кругов, штраф за пропуск, звук.
2. Команды ходят по очереди. Экран «Ход команды X — передайте телефон объясняющему» → «Начать» → отсчёт 3-2-1.
3. Ход: показывается карточка (картинка, название, 2–3 симптома). «Угадали» = +1, «Пропуск» = −1 (или 0, если штраф выключен). Сразу следующая карточка.
4. Время вышло → гудок, текущая карточка остаётся как «последнее слово»: одно нажатие «Угадали»/«Пропуск» и ход заканчивается.
5. Итоги хода: все карточки хода с картинками (✓/✗), тапом можно исправить ошибку; счёт пересчитывается. «Дальше» → ход следующей команды.
6. Игра заканчивается после N кругов (каждая команда сходила N раз). Финал: победитель, таблица, конфетти, «Ещё раз».
7. Одна команда — режим рекорда: суммарный счёт, лучший результат сохраняется.
   Карточка в этом режиме двусторонняя (изменено в фазе 2, 2026-10-20): лицевая сторона — только «Жалобы» (2–3 симптома, без картинки и названия). Тап по карточке переворачивает её — картинка и название болезни. Потом игрок сам выбирает «Угадали» (+1) или «Не угадали» (−1, по настройке штрафа). Пока карточка не перевёрнута, кнопки ответа и свайп неактивны. Пока карточка открыта, таймер стоит (на градуснике плашка «пауза», серая ртуть, без тиканья); после «Угадали»/«Не угадали» снова идёт со следующей закрытой карточкой (изменено 2026-10-20, итерация 2). Время выходит только пока карточка закрыта; в последнем слове «Не угадали» = 0.
8. Карточки не повторяются, пока колода не кончится (учёт сыгранных между партиями). Колода кончилась → сыгранные перемешиваются заново (кроме карточек текущего хода).
**Состояния и переходы**: Главная → Настройка → Передача хода → Отсчёт → Ход ⇄ Пауза → Последнее слово → Итоги хода → (Передача хода | Финал) → Главная/Ещё раз. С любого экрана игры — «Выйти» с подтверждением.
**Граничные случаи**:
- Свернули Safari / звонок / блокировка во время хода → таймер на паузе, по возвращении экран «Пауза — продолжить».
- iOS выгрузил вкладку / перезагрузка → партия восстанавливается из сохранения (на экран передачи хода или паузы).
- Двойной тап, спам кнопок → ввод блокируется на время анимации смены карточки.
- Случайное нажатие → правится на экране итогов.
- Счёт уходит в минус → допускается.
- Ничья после последнего круга → «Ничья!», общая победа.
- Беззвучный режим iPhone → игра работает; последние 5 секунд таймер пульсирует красным.
- Экран гаснет → Wake Lock на время хода (если не поддерживается — без него).
- Поворот в ландшафт → подсказка «Поверните телефон», игра только в портрете.
- Открыли на компьютере → работает; клавиши: ↑/пробел — угадали, ↓ — пропуск, Esc — пауза.
**Параметры**:
- ROUND_SECONDS — 60 — 30–90 — длительность хода
- ROUNDS — 3 — 1–5 — число кругов
- TEAMS — 2 — 1–4 — число команд
- SKIP_PENALTY — 1 — 0–1 — сколько отнимает пропуск
- WARNING_SECONDS — 5 — 0–10 — с какого момента тикает и пульсирует таймер
- COUNTDOWN_SECONDS — 3 — 0–5 — отсчёт перед ходом
- SWIPE_THRESHOLD_PX — 60 — 30–120 — длина свайпа для срабатывания
- CARD_SWITCH_MS — 250 — 150–500 — анимация смены карточки (и блок ввода)
- FLIP_MS — 450 — 200–800 — переворот карточки в игре на рекорд (добавлен в фазе 2)
- DECK_SIZE — 60 карточек
**Ввод и отклик**: большие кнопки «Угадали» (зелёная, ✓) и «Пропуск» (красная, ✗) внизу под большой палец + свайп карточки вверх/вниз. Отклик: карточка улетает вверх/вниз, всплывает «+1»/«−1», короткий звук. Последние 5 с — тиканье и красный пульсирующий таймер; конец — гудок. Финал — конфетти. Вибрации нет (Safari на iPhone не поддерживает).
**UI / визуал / звук**: яркие мультяшные SVG-персонажи-органы с лицами и предметами (грелка, градусник, платок), цвет карточки по системе органов (живот, нос-горло, кожа, голова…). Крупный шрифт (игрокам 30+): название болезни ≥ 32 px, симптомы ≥ 18 px, высокий контраст. Портрет, учёт выреза и home-индикатора iPhone. Звуки синтезируются в браузере, кнопка вкл/выкл. На главной мелко: «Игра шуточная, не медицинский справочник».
**Связи с существующими системами**: проект новый. Хранение — localStorage: настройки, имена команд, текущая партия, сыгранные карточки, рекорд. Офлайн после первого открытия (service worker), «На экран Домой» — на весь экран.
**Не входит в scope**: режимы «на лоб» и «викторина», онлайн-мультиплеер, свои карточки, колода 18+, другие языки, App Store, аккаунты, аналитика.
**Отклонённые альтернативы**:
- «Телефон на лоб» — отложен: нужен доступ к датчикам на iOS, сначала проверим основной режим.
- Соло-викторина — нужно много точного текста, быстро надоедает.
- Арт из нейросети — ручная работа на каждую карточку; SVG кодом дешевле и в едином стиле.
- Арт и название оригинала — чужие права.
- Тяжёлые диагнозы — риск задеть кого-то за столом.
- Пропуск = 0 — выгодно пропускать всё сложное.
- Колода 40 — повторы уже в первой партии.
