# Угадай болезнь

Шуточная объяснялка для компании на одном iPhone. Объясняющий видит карточку с болезнью и описывает симптомы, не называя её. Команда угадывает, пока не кончилось время на градуснике.

Играть: https://screamart.github.io/ugaday-bolezn/ — откройте в Safari, ничего устанавливать не нужно.

Чтобы игра была под рукой: в Safari нажмите «Поделиться» → «На экран „Домой“». Иконка откроет игру на весь экран, и после первого открытия она работает без интернета.

Все 60 карточек с персонажами и подсказками: https://screamart.github.io/ugaday-bolezn/deck.html

Игра шуточная и не заменяет медицинский справочник.

## Правила

- От 1 до 4 команд, ходят по очереди, ход — 60 секунд.
- «Угадали» — +1, «Пропуск» — −1. Штраф за пропуск можно выключить в настройках.
- Когда время вышло, остаётся последнее слово: эту карточку ещё можно угадать.
- После хода видно все карточки. Ответ, нажатый по ошибке, можно исправить.
- Побеждает команда, которая наберёт больше очков за 3 круга.
- Одна команда — игра на рекорд. На карточке только жалобы. Нажмите на карточку, чтобы увидеть ответ, и отметьте, угадали или нет. Пока карточка открыта, таймер стоит.

## Разработка

Сборки нет: HTML, CSS и JavaScript-модули раздаются как есть.

```sh
npm test          # юнит-тесты
npm run serve     # http://localhost:8080
npm run e2e       # партия в браузере на размерах iPhone и без сети (нужен Playwright)
npm run icons     # перерисовать иконки (нужен Playwright)
```

Карточки лежат в `js/cards.js`, персонажи рисуются кодом в `js/art.js`. После любых изменений поднимите `VERSION` в `sw.js`, чтобы у игроков обновилась сохранённая копия.
