# Угадай болезнь

Веб-игра-объяснялка для iPhone: открывается по ссылке в Safari, без установки. Хостинг — GitHub Pages из ветки `main` (корень репозитория), адрес `https://screamart.github.io/ugaday-bolezn/`.

## Устройство

- Без сборки и без зависимостей: чистые HTML, CSS и ES-модули. Что лежит в репозитории, то и раздаётся.
- Все пути относительные (`./…`) — игра живёт в подпапке `/ugaday-bolezn/`.
- `js/game.js` — правила и состояние, без DOM. Побочные эффекты отдаёт событиями через `emit(type, payload)`. Время приходит параметром `tick(dt)`.
- `js/render.js` — HTML-шаблоны экранов и точечные обновления DOM. `js/input.js` — клики, свайпы, клавиатура, сворачивание, поворот. `js/main.js` — связывает всё и крутит цикл `requestAnimationFrame`.
- `js/cards.js` — колода, `js/art.js` — SVG-персонажи из конструктора «тело + лицо + предметы».
- Числа (тайминги, пороги, лимиты) — только в `js/config.js`, значения утверждены в прототипе. Цвета и шрифты — CSS-переменные в `:root` в `css/game.css`.

## Команды

- `npm test` — юнит-тесты (`node --test "tests/*.test.js"`).
- `npm run serve` — локальный сервер на :8080.
- `npm run e2e` — партия в Chromium через Playwright на размерах iPhone и компьютера; нужен запущенный `npm run serve` и установленный Playwright.

## Правила

- Перед push — `npm test` и `npm run e2e` зелёные.
- Подсказки на карточке не должны содержать однокоренных с названием слов; `tests/cards.test.js` ловит очевидные случаи.
- Тексты интерфейса — на русском, обращение на «вы».
- Документы фичи: `.claude/features/` (бриф и журнал, план, исходник прототипа).
